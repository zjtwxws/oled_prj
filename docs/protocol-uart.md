# UART 自定义二进制帧协议 (v3.1)

> 适用于 PC 上位机 ↔ STM32F407 之间的串口通信。
> RK3506 网关作为可选中继，帧格式保持不变。

---

## 1. 物理层参数

| 参数 | 值 |
|------|------|
| 接口 | UART (TTL) |
| 波特率 | 115200 |
| 数据位 | 8 |
| 停止位 | 1 |
| 校验位 | 无 (8N1) |
| 流控 | 无 |

---

## 2. 帧格式

```
┌──────┬──────┬──────┬──────┬────────────┬──────┬──────┐
│ SOF  │ LEN  │ CMD  │ SEQ  │   DATA     │ CRC8 │ EOF  │
│ 1 B  │ 1 B  │ 1 B  │ 1 B  │  0~251 B   │ 1 B  │ 1 B  │
└──────┴──────┴──────┴──────┴────────────┴──────┴──────┘
```

| 字段 | 长度 | 说明 |
|:----:|:----:|:----|
| **SOF** | 1 B | 帧起始符，固定 `0xA5` |
| **LEN** | 1 B | DATA 段字节数，范围 0~251 |
| **CMD** | 1 B | 命令码 |
| **SEQ** | 1 B | 帧序号，应答帧回填相同序号 |
| **DATA** | 0~251 B | 负载数据 |
| **CRC8** | 1 B | CRC-8-ATM 校验和，覆盖 SOF ~ DATA |
| **EOF** | 1 B | 帧结束符，固定 `0x5A` |

**最大帧长**: `1(SOF) + 1(LEN) + 1(CMD) + 1(SEQ) + 251(DATA) + 1(CRC8) + 1(EOF) = 257` 字节。

## 3. 命令码定义

### 3.1 下行命令 (PC → STM32)

| CMD | 命令 | 功能 | DATA 段 |
|:---:|:----:|:----|:---------|
| `0x01` | `CMD_LED_CTRL` | LED 控制 | 1 B: `0`=关, `1`=开, `2`=闪烁 |
| `0x02` | `CMD_DISPLAY_MODE` | 设置显示模式 (v3.1) | 1 B: bit7=远程标记, 低7位=子模式 (见 §3.4) |
| `0x03` | `CMD_TEXT_CONTENT` | 下发文字内容 | 变长，UTF-8 编码，≤ 200 B |
| `0x04` | `CMD_TIME_SYNC` | 时间同步 | 7 B 时间数据 (见 §4.1) |
| `0x05` | `CMD_WEATHER_DATA` | 天气数据 | 4 B 天气数据 (见 §4.2) |
| `0x06` | `CMD_BOOT_TEXT` | 设置上电默认文字 | 变长，UTF-8 编码，写入 Flash |
| `0x20` | `CMD_FRAME_SYNC` | OLED 帧缓冲分段下发 (仅远程模式) | `[seg(1B)][total(1B)][payload ≤200B]` |

### 3.2 上行命令 (STM32 → PC)

| CMD | 命令 | 功能 | DATA 段 |
|:---:|:----:|:----|:---------|
| `0x10` | `CMD_LED_STATUS` | LED 状态上报 | 1 B: 当前 LED 状态 |
| `0x11` | `CMD_MODE_STATUS` | 显示模式上报 (v3.1) | 2 B: `[is_remote(1B)][sub_mode(1B)]` |
| `0x12` | `CMD_KEY_EVENT` | 按键事件上报 | 2 B: [键号][动作] (见 §4.3) |

### 3.3 应答命令

| CMD | 命令 | 功能 | DATA 段 |
|:---:|:----:|:----|:---------|
| `0xF0` | `CMD_ACK` | 成功应答 | LEN=0，无数据 |
| `0xFF` | `CMD_NAK` | 失败/错误 | 1 B: 错误码 (见 §3.5) |

### 3.4 显示模式码 (CMD_DISPLAY_MODE, v3.1)

格式: 1 字节 `[bit7][低7位]`

| bit7 | 含义 |
|:----:|:----|
| 0 | 本地模式: 低7位=特效号 (0~6) |
| 1 | 远程模式: 低7位=子模式 (0=TEXT, 1=TIME, 2=WEATHER, 3=DATE) |

**特效号** (本地模式 + 远程 TEXT 子模式):

| 值 | 模式 |
|:-:|:----|
| 0 | 静态显示 |
| 1 | 向左滚动 |
| 2 | 向右滚动 |
| 3 | 向上滚动 |
| 4 | 向下滚动 |
| 5 | 翻页显示 |
| 6 | 淡入淡出 |

### 3.5 错误码 (NAK)

| 错误码 | 含义 |
|:-----:|:------|
| `0x01` | CRC 校验失败 |
| `0x02` | 未知命令码 |
| `0x03` | 参数错误/越界 |
| `0x04` | Flash 写入失败 |
| `0x05` | 系统忙 |

## 4. DATA 段详细格式

### 4.1 时间同步数据 (CMD_TIME_SYNC, 0x04)

> 注: 时间采用**原始值编码**（非 BCD 码），直接按二进制整数值传输。

| 偏移 | 长度 | 含义 | 范围 |
|:---:|:----:|:----|:----:|
| 0 | 1 B | 年 (年份 - 2000) | 0~99 |
| 1 | 1 B | 月 | 1~12 |
| 2 | 1 B | 日 | 1~31 |
| 3 | 1 B | 时 | 0~23 |
| 4 | 1 B | 分 | 0~59 |
| 5 | 1 B | 秒 | 0~59 |
| 6 | 1 B | 星期 | 0=周日, 1~6=周一~周六 |

共 **7 字节**。

### 4.2 天气数据 (CMD_WEATHER_DATA, 0x05)

| 偏移 | 长度 | 含义 | 说明 |
|:---:|:----:|:----|:----|
| 0 | 1 B | 天气类型 | 编码见下表 |
| 1 | 1 B | 温度 | 有符号 (`int8_t`), -20~50 ℃ |
| 2 | 1 B | 湿度 | 0~100 % |
| 3 | 1 B | 风向 | 编码见下表 |

共 **4 字节**。

**天气类型编码**:

| 值 | 0 | 1 | 2 | 3 | 4 | 5 | 6 |
|:--:|:-:|:-:|:-:|:-:|:-:|:-:|:-:|
| 天气 | 晴 | 多云 | 阴 | 小雨 | 大雨 | 雷雨 | 雪 |

**风向编码**:

| 值 | 0 | 1 | 2 | 3 | 4 | 5 | 6 | 7 |
|:--:|:-:|:-:|:-:|:-:|:-:|:-:|:-:|:-:|
| 风向 | 北 | 东北 | 东 | 东南 | 南 | 西南 | 西 | 西北 |

### 4.3 按键事件 (CMD_KEY_EVENT, 0x12)

| 偏移 | 长度 | 含义 | 说明 |
|:---:|:----:|:----|:----|
| 0 | 1 B | 键号 | 1=KEY1, 2=KEY2, 3=KEY3, 4=KEY4 |
| 1 | 1 B | 动作 | 0=短按, 1=长按, 2=释放, 3=长按重复(仅菜单内部使用, 不上报) |

> 注: `KEY_EVENT_LONG_PRESS_REPEAT`(3) 仅供 STM32 菜单系统快速滚动使用，不通过 CMD_KEY_EVENT 上报上位机。上位机接收到的事件类型只有 0/1/2。

### 4.4 帧缓冲分段 (CMD_FRAME_SYNC, 0x20) — 仅远程模式

| 偏移 | 长度 | 含义 | 说明 |
|:---:|:----:|:----|:----|
| 0 | 1 B | 分片序号 | 当前分片编号 (0-based) |
| 1 | 1 B | 总分片数 | 分片总数, 固定 6 (1024/200 向上取整) |
| 2+ | ≤200 B | 帧缓冲片段 | 每段 payload ≤200 字节 |

- 全部分片收齐后组装为完整 1024 字节 OLED 显存 (128×64 / 8=1024)
- 首段 (seg=0) 清空帧缓冲
- 本地模式下 STM32 收到此命令回复 NAK(0x05)

### 4.5 模式状态上报 (CMD_MODE_STATUS, 0x11, v3.1)

| 偏移 | 长度 | 含义 | 说明 |
|:---:|:----:|:----|:----|
| 0 | 1 B | is_remote | 0=本地模式, 1=远程模式 |
| 1 | 1 B | sub_mode | 本地: 特效号(0~6); 远程: 子模式(0~3) |

## 5. CRC-8-ATM 算法

- **多项式**: `x⁸ + x² + x + 1` (`0x07`)
- **初始值**: `0x00`
- **计算范围**: SOF 字节开始，到 DATA 段最后一个字节结束（不含 CRC 本身）
- 实现使用查表法加速

```c
uint8_t proto_crc8(const uint8_t *data, uint16_t len)
{
    uint8_t crc = 0x00;
    while (len--) {
        crc = crc8_table[crc ^ *data++];
    }
    return crc;
}
```

## 6. 通信规则

1. **主从关系**: PC 上位机为主设备，主动发起下行指令；STM32 为从设备，收到指令后必须回复 ACK 或 NAK。
2. **主动上报**: STM32 可主动上行按键事件(`CMD_KEY_EVENT`)，上位机需回复 ACK。模式状态和 LED 状态在被查询或变更时上报。
3. **超时重传**: 发送方发出指令后等待 ACK，超时 **500 ms** 则重发，最多重发 **3 次**。
4. **序号管理**: SEQ 字段递增，应答帧回填被应答帧的 SEQ。
5. **CRC 校验**: 接收方校验 CRC，匹配则继续等待 EOF；不匹配则丢弃帧，可回复 NAK(0x01)。
6. **远程模式帧缓冲**: 仅远程模式下发送 `CMD_FRAME_SYNC`。每段 payload ≤200 字节，共 6 段，段间间隔 2ms。

## 7. 接收状态机

协议接收器基于有限状态机实现，状态转移如下：

```
WAIT_SOF → WAIT_LEN → WAIT_CMD → WAIT_SEQ → WAIT_DATA
                                          ↘ WAIT_CRC → WAIT_EOF → 帧完成
                                               ↙ (CRC 失败则回到 WAIT_SOF)
```

| 状态 | 处理逻辑 |
|:----|:--------|
| `WAIT_SOF` | 等待 `0xA5`，收到后初始化 CRC 并进入 `WAIT_LEN` |
| `WAIT_LEN` | 接收长度字段，> 251 则回到 `WAIT_SOF`，否则继续 |
| `WAIT_CMD` | 接收命令码 |
| `WAIT_SEQ` | 接收序号；若 LEN=0 则跳过 DATA 直接进入 `WAIT_CRC` |
| `WAIT_DATA` | 接收 DATA 段，收满 LEN 字节后进入 `WAIT_CRC` |
| `WAIT_CRC` | 比对 CRC，匹配则进入 `WAIT_EOF`，否则回到 `WAIT_SOF` |
| `WAIT_EOF` | 等待 `0x5A`，匹配则标记帧完成，回到 `WAIT_SOF` |

## 8. 报文示例

### 8.1 时间同步帧

```
A5 07 04 00 19 01 07 0E 1E 00 03 8F 5A
│  │  │  │ └─────── DATA ────────┘ │  │
│  │  │  │    19=年(2025) 01=月    │  │
│  │  │  │    07=日 0E=时(14)      │  │
│  │  │  │    1E=分(30) 00=秒      │  │
│  │  │  │    03=星期三             │  │
│  │  │  └──── SEQ=0               │  │
│  └─────── CMD=0x04 (时间同步)     │  │
└────────── LEN=7 (7字节数据)      │  │
                                   │  │
                  CRC8=0x8F ───────┘  │
                  EOF=0x5A ───────────┘
```

### 8.2 模式切换帧 (v3.1: 切换到远程+TIME)

```
A5 01 02 00 82 2A 5A
│  │  │  │ │  │  │
│  │  │  │ │  │  └─ EOF=0x5A
│  │  │  │ │  └──── CRC8=0x2A
│  │  │  │ └─────── DATA=0x82 (bit7=1远程, 低7位=2=TIME)
│  │  │  └───────── SEQ=0
│  │  └──────────── CMD=0x02 (DISPLAY_MODE)
│  └─────────────── LEN=1
└────────────────── SOF=0xA5
```

### 8.3 ACK 应答

```
A5 00 F0 00 65 5A
│  │  │  │  │  │
│  │  │  │  │  └─ EOF
│  │  │  │  └──── CRC8
│  │  │  └─────── SEQ (与所应答帧一致)
│  │  └────────── CMD=0xF0 (ACK)
│  └───────────── LEN=0
└──────────────── SOF
```
